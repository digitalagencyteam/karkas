# КП LIVSKY для КАРКАС (karkas-hr.pro)

Статический сайт без сборки. Открыть `index.html` в браузере или выложить папку на любой хостинг.

- Тексты и цены: `build.py` (блок ЦЕНЫ вверху). После правок: `python3 build.py`, он перезапишет `index.html`.
- Стили: `style.css` (токены из website: Manrope, градиент #8fb0ff → #a77cff, чёрные карточки, маскот-звезда).
- Картинки: `img/mascot` (из website), `img/cases` (обложки кейсов LIVSKY), `img/proof` (скриншоты замеров КАРКАСа).
- В `index.html` стоит `noindex`, страница закрыта от поисковиков.

Цены в долларах и рядом в рублях по курсу FX в build.py (82 ₽/$), ставка части 1: $37/ч. SEO-ведение: обычная цена SEO_FULL ($1 000), для КАРКАСа $900 как цена первых клиентов. Цены частей 2 и 3 и скидка 10% за комплекс: черновая оценка, согласовать с коллегами.
